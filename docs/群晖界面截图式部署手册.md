# 群晖界面截图式部署手册（精简版）

适用范围：DSM 7.x + Container Manager。

## 截图 1：打开 Container Manager

- 路径：DSM 主界面 -> 套件中心 -> Container Manager。
- 目标：确认 Container Manager 已安装并可打开。

## 截图 2：准备项目目录

- 路径：File Station -> 例如 `/volume1/docker/docscool`。
- 将以下文件夹上传到该目录：
  - `backend/`
  - `frontend/`
  - `docker-compose.yml`

## 截图 3：编辑 backend/.env

- 在 File Station 中打开 `backend/.env`。
- 最少确认以下配置：

```dotenv
FLASK_ENV=production
APP_SECRET_KEY=替换为随机字符串
DATABASE_URL=sqlite:///instance/contracts.db

SYNOLOGY_BASE_URL=https://你的NAS地址:5001
SYNOLOGY_VERIFY_SSL=false

CONTRACT_STORAGE_MODE=remote
CONTRACT_STORAGE_ROOT=/volume1/contracts
SYNOLOGY_FILESTATION_ROOT=/contracts

SYNOLOGY_UPLOAD_ACCOUNT=DSM上传账号
SYNOLOGY_UPLOAD_PASSWORD=DSM上传密码
SYNOLOGY_UPLOAD_SESSION=FileStation
```

## 截图 4：创建 compose 环境变量文件（可选）

- 在项目根目录新建 `.env`（与 `docker-compose.yml` 同级）。
- 写入 NAS 端口和挂载参数：

```dotenv
DOCSCOOL_BACKEND_PORT=5000
DOCSCOOL_FRONTEND_PORT=8080
DOCSCOOL_STORAGE_HOST_PATH=/volume1/contracts
```

- 如果你把合同放在别的共享目录，只改 `DOCSCOOL_STORAGE_HOST_PATH` 即可。

## 截图 5：在 Container Manager 新建项目

- 进入 `Container Manager -> 项目`。
- 点击 `新增`。
- 选择项目路径：`/volume1/docker/docscool`。
- 使用目录内现有 `docker-compose.yml`。
- 点击部署。

## 截图 6：确认容器运行

部署成功后应看到两个容器：

- `contract-backend`
- `contract-frontend`

状态应为“运行中”。

## 截图 7：访问系统

- 前端地址：`http://NAS_IP:8080`
- 后端健康检查：`http://NAS_IP:5000/api/health`

健康检查返回：

```json
{"status":"ok"}
```

说明后端正常。

## 截图 8：上线后最小验收

1. 使用 DSM 账号登录。
2. 新建合同并上传 PDF。
3. 打开合同编辑框，确认 PDF 能预览。
4. 在全屏预览中测试“下载原文件”。
